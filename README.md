# AI & Machine Learning Workshop – Alma Fiesta 2024, IIT Bhubaneswar

## Overview

This repository contains notebooks, assignments, and hands-on exercises completed during the **AI & Machine Learning with Data Science using Python Workshop** conducted as part of **Alma Fiesta 2024 at IIT Bhubaneswar**.

The workshop provided practical exposure to Python programming, data analysis, statistics, visualization, and introductory machine learning concepts. The exercises in this repository helped build the foundation for my later projects in Data Science, NLP, and Machine Learning.
